# Contributing

The first-party core is licensed under Apache-2.0. Submit bounded PRs with the source SHA, affected contracts, actual checks and remaining limitations.

Use the existing formatting, offline verification and negative-test conventions. Do not modify vendored code to repair application behavior. Keep private modules optional and preserve all third-party notices.

No production, hosted-runner or general hostile-code claim follows from local synthetic tests. Do not commit secrets, private platform source, datasets, weights or internal operational evidence.
